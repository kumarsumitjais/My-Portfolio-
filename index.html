This project focuses on predicting the Air Quality Index (AQI) to assess environmental health conditions in Hyderabad over a span of five years. The dataset, consisting of synthetic data, includes 8 key air contaminants and 6 meteorological factors such as temperature, humidity, wind speed, and pressure. Various regression models, including Linear Regression, Decision Tree Regressor, and Random Forest Regressor, were implemented and compared for performance. After comprehensive evaluation, the Random Forest Regressor achieved the highest accuracy of 93%, effectively capturing complex interactions among pollutants and weather variables. The project demonstrates the integration of data preprocessing, feature analysis, and model optimization techniques to ensure reliable AQI predictions. These insights can aid policymakers and environmental agencies in identifying pollution trends and taking preventive measures.

This project develops a machine learning model to classify tweets as either "Hate speech" or "offensive language." The model is built using a labeled Twitter dataset, which is first filtered to create a binary classification problem, excluding neutral tweets. A comprehensive preprocessing pipeline is applied to the text data. This involves converting tweets to lowercase, removing all URLs, punctuation, and HTML tags, and filtering out common stopwords using NLTK. The SnowballStemmer is then used to normalize the words to their root form. For feature extraction, the cleaned tweet text is transformed into a numerical sparse matrix using CountVectorizer, which represents each tweet based on its word counts. A DecisionTreeClassifier model is trained on this vectorized data. The model's performance is evaluated on a 33% test split, where it achieves a high overall accuracy of 93.55%. The classification report further shows a weighted F1-score of 93.6% and strong precision (97%) for identifying "Hate speech," demonstrating the model's effectiveness.

This project focuses on identifying and filtering unwanted or malicious messages using machine learning. The goal was to develop a model capable of accurately classifying messages as spam or non-spam by analyzing linguistic patterns and message structures. The dataset was preprocessed through techniques such as tokenization, stopword removal, and TF-IDF vectorization to convert text data into numerical form. Various models including Naïve Bayes, Logistic Regression, and Support Vector Machine (SVM) were trained and compared. Among them, the Naïve Bayes classifier delivered the best accuracy due to its efficiency in handling probabilistic text classification tasks. The project highlights the importance of data preprocessing, feature extraction, and evaluation metrics such as precision, recall, and F1-score in developing robust spam filters. This model can be integrated into real-world applications like email filtering systems, chat moderation tools, or social media monitoring platforms to enhance digital communication safety.

This project develops a Breast Cancer Prediction Model using deep learning to classify tumors as benign or malignant from medical images. The model leverages transfer learning by employing the pre-trained VGG16 architecture. The convolutional base of VGG16 is frozen, and custom layers—including Flatten, Dense (512 units with ReLU), Dropout (0.5), and a final Dense output layer (1 unit with sigmoid activation)—are added for binary classification. The process involves splitting the dataset into training, validation, and test sets, with data augmentation (rotation, flipping, etc.) applied to the training images to improve model generalization. The model is compiled using the 'adam' optimizer and 'binary_crossentropy' loss. During training for 50 epochs, callbacks like ModelCheckpoint (to save the best model), EarlyStopping (to prevent overfitting), and ReduceLROnPlateau (to adjust the learning rate) are used to optimize performance. The final model's accuracy was evaluated on the test set, successfully achieving 87% accuracy and demonstrating a practical application of CNNs for aiding in early medical diagnosis.

Farmer Sakha is an intelligent agriculture solution designed to empower farmers with real-time insights and smart decision-making tools. The system integrates AI, IoT, and weather forecasting to monitor key agricultural factors and enhance farm productivity. It features simulated IoT soil sensors that analyze soil moisture and nutrient levels, helping farmers optimize fertilizer use and irrigation schedules. The integrated AI-powered crop disease detection model uses image processing to identify diseases at early stages, reducing crop loss and improving yield quality. Through the OpenWeather API, Farmer Sakha provides real-time weather updates, assisting in accurate planning for sowing and irrigation. A multilingual mobile application serves as the user interface, ensuring accessibility for farmers from diverse regions, with voice support for convenience. By combining real-time monitoring, predictive analytics, and user-friendly interaction, Farmer Sakha brings technology closer to the fields, enabling farmers to make data-driven decisions. Ultimately, Farmer Sakha aims to promote sustainable farming, reduce resource wastage, and boost productivity, contributing to smarter and more resilient agriculture.
